# KNOT タイムカード V1.3.1

管理画面と打刻修正を追加したテスト版です。

## 追加機能
- 管理者PINによる管理画面
- 打刻一覧（直近100件）
- 打刻の「出勤／退勤」変更
- 打刻日時の変更
- 修正理由・修正者の保存
- 修正履歴（直近100件）
- スタッフごとの時給・交通費・PIN変更

## テスト用PIN
- 田中: 1234
- 佐藤: 2345
- 山田: 3456
- 大山: 4567
- 管理者: 9999

本番利用前に管理者PINを変更してください。現在はテスト用としてWorker内に記載しています。

## 注意
- 店舗回線判定は現在、確認済みのIPv4/IPv6プレフィックスを使用しています。
- D1スキーマはWorker初回利用時に自動初期化するテスト方式です。
- PINは現在平文保存です。本番化ではハッシュ化、管理者認証強化、権限分離を行います。
- 深夜時間計算は実装していません。
