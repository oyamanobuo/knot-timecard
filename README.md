# KNOT タイムカード V1.6

管理画面・打刻修正・スタッフ管理・給与計算対応版です。

## 追加機能
- 管理者PINによる管理画面
- 打刻一覧・修正履歴
- スタッフ名・時給・交通費・PIN変更
- スタッフ追加・削除
- 月別給与計算・CSV出力
- PINの試行回数制限（総当たり対策）
- 二重打刻防止（3秒以内の連続打刻をブロック）
- 深夜時間計算なし

## 初期セットアップ（必須）

このアプリは管理者PINをソースコードに含めていません。デプロイ前に、Cloudflareのシークレットとして管理者PINを設定してください。

```
wrangler secret put ADMIN_PIN
```

スタッフの登録は、管理者PINでログイン後に管理画面の「スタッフ追加」から行ってください。ソースコードやREADMEにスタッフの実PINを記載しないでください。

## セキュリティに関する注意

過去のバージョンでは、管理者PINおよびテスト用スタッフPINがソースコード・READMEに平文で記載されていました。このリポジトリを一度でもPublicにした、または他者と共有した場合は、記載されていたPIN（田中/佐藤/山田/大山/管理者）は漏洩している可能性があるため、管理画面から必ず変更してください。
